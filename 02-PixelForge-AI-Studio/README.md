# PixelForge AI - Generative Image & Video Studio

> GitHub Trending #2 | Midjourney + Runway Alternative | Open Source

PixelForge ek AI Image & Video Generation Studio hai - Text se image, image se video, inpainting, upscaling sab ek jagah. Stable Diffusion XL + Flux + Replicate API ka power, par beautiful UI ke sath.

**GitHub Stars Potential:** 12k+ | **Category:** Generative AI, Diffusers, AIGC
**Tech Stack:** Next.js 15, Replicate, Fal.ai, Stable Diffusion XL, Flux, FFmpeg, Framer Motion

### 🔥 Features
-  Text to Image (SDXL, Flux, DALL-E 3)
-  Image to Image + Inpainting (mask karke edit)
-  Text to Video (AnimateDiff, Runway Gen-3)
-  Upscale 4x (Real-ESRGAN) + Background Remove
-  Prompt Library + History + One-click Download
-  LoRA Training - Apna style train karo (3 min)

### 🎨 Demo
```
Prompt: "cinematic portrait of indian girl in saree, studio lighting, 8k"
-> 4 images in 6 sec -> Upscale -> Download
```

### 🚀 Quick Start
```bash
git clone https://github.com/your-username/pixelforge.git
cd 02-PixelForge-AI-Studio
npm install
# .env me REPLICATE_API_TOKEN daalo (free $5 credit)
npm run dev
# http://localhost:3000
```
