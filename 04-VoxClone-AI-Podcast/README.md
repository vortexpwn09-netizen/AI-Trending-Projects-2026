# VoxClone AI - Voice Cloning & Podcast Studio

> GitHub Trending #4 | ElevenLabs Alternative | Open Source

VoxClone se 30 sec audio se tumhari voice clone karo, fir text se speech, podcast, dubbing sab banao - Hindi, English sab languages.

**GitHub Stars Potential:** 11k+ | **Category:** Voice AI, TTS, STT, Audio
**Tech Stack:** Next.js, FastAPI, Coqui XTTS, Whisper, Bark, FFmpeg, ElevenLabs API, RVC

### 🔥 Features
-  30 sec me Voice Clone (XTTS-v2)
-  Text to Speech - 29 languages, emotion control
-  Podcast Studio - Script -> Multi-voice podcast
-  Dubbing - Video upload -> Hindi to English dub
-  Voice Changer (RVC) - Real-time
-  API + Playground

### 🎙️ Demo
```
1. Upload 30 sec voice sample (mp3)
2. Type: "Namaste dosto, aaj ka podcast shuru karte hain"
3. Generate -> 5 sec me tumhari awaz me audio
```

### 🚀 Quick Start
```bash
git clone https://github.com/your-username/voxclone.git
cd 04-VoxClone-AI-Podcast
docker-compose up -d  # XTTS + Whisper
npm install --prefix frontend
pip install -r backend/requirements.txt
# .env me ELEVENLABS_KEY (optional, local free bhi)
npm run dev
```
