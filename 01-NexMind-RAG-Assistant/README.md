# NexMind - Personal RAG Knowledge Assistant

> GitHub Trending #1 | Most Useful AI Project 2026 | Your Second Brain

NexMind ek AI-powered Personal Knowledge Assistant hai jo tumhare PDFs, Docs, Notion, YouTube videos aur website data ko ingest karke uspar instant chat karne deta hai. Socho NotebookLM + ChatGPT + Notion AI ka combo - par fully open-source aur tumhara data tumhare paas.

**GitHub Stars Potential:** 15k+ | **Category:** RAG, LLM, Vector DB
**Tech Stack:** Next.js 15, FastAPI, LangChain, PGVector/Qdrant, OpenAI/Gemini, Clerk Auth

### 🔥 Kya Problem Solve Karta Hai?
- Students: 500 page PDF se 5 sec me answer
- Professionals: Meeting notes, docs se instant Q&A
- Creators: YouTube video ka summary + chat

### ✨ Key Features
1.  Drag & Drop - PDF, DOCX, TXT, MD, URL, YouTube link upload
2.  AI Chat with Citations - Har answer ke sath source page number
3.  Multi-LLM Support - GPT-4o, Gemini 1.5 Pro, Claude 3.5, Ollama (local)
4.  Smart Chunking & Hybrid Search - Vector + Keyword search
5.  Chat History + Shareable Links
6.  Chrome Extension + Mobile PWA

### 🚀 Quick Start (2 min)
```bash
git clone https://github.com/your-username/nexmind.git
cd 01-NexMind-RAG-Assistant
docker-compose up -d  # Qdrant + Postgres
pip install -r backend/requirements.txt
npm install --prefix frontend
# .env me OPENAI_API_KEY daalo
npm run dev
```
